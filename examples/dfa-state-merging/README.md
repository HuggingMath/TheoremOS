# Merge states without changing a finite automaton's language

[简体中文](README.zh-CN.md)

Suppose you want to merge several pairs of states in a deterministic finite automaton. After merging a pair, its successors under each input symbol must also be equivalent. All states in a resulting class must agree on whether to accept the empty word.

The Lean example treats each input symbol as a unary operation on the states. The archived lemma `eqvGenTranslate_compatible` shows that the equivalence generated by the proposed pairs is stable under these transitions. The theorem `merge_safe_iff` proves that each class has a consistent acceptance decision exactly when both states in every proposed pair accept the same continuation words. The definition `mergedDFA` uses these classes as states, and `merged_accepts` proves that the quotient automaton recognizes the original language. [Archived congruence lemma](https://github.com/HuggingMath/TheoremOS/blob/84e40d87325052a6489f9e9225b666c622f2c405/data/proofs/openai_finite_congruence_graph/Submission.lean#L222)

The example machine reads bits and accepts when it has seen an even number of ones. Its four reachable states store two bits. Reading a one flips the parity bit, and reading a zero flips a second bit that does not affect acceptance. Identifying the two even states forces the two odd states to merge as well. Lean verifies that the quotient has exactly two states and preserves the language.

## Check locally

Run these commands from this directory with Git, curl, Elan, and `sha256sum`. The configuration pins Lean `4.34.1` and Mathlib `d13f23b723b8a846827a245b89c10fc7d3f11612`.

```bash
curl -fLsS \
  https://raw.githubusercontent.com/HuggingMath/TheoremOS/84e40d87325052a6489f9e9225b666c622f2c405/data/proofs/openai_finite_congruence_graph/Submission.lean \
  -o ArchivedFiniteCongruence.lean
sha256sum -c - <<'EOF'
6b32441db35b95aed73a9f7acdb44c57bc0f5c3e1556113478e96f921b022a3f  ArchivedFiniteCongruence.lean
EOF
lake update --keep-toolchain
lake exe cache get
lake build ArchivedFiniteCongruence
lake env lean DFAStateMerging.lean
```

Lean checked the merge criterion, the quotient language, and the four-state example. The reachability theorem uses no axioms. The other declarations printed by the check use `propext`, `Classical.choice`, and `Quot.sound`.
