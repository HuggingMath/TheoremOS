# TheoremOS 能力与协作范围

[English](./CAPABILITIES.md) | [返回首页](../README.zh-CN.md) | [访问申请](./ACCESS.md) | [快速上手](./GETTING-STARTED.zh-CN.md) | [案例研究](./CASE-STUDY.zh-CN.md) | [证明档案与观察](./EVALUATION.zh-CN.md) | [独立复核指南](./VERIFY.zh-CN.md)

TheoremOS 面向数学家与形式化研究者，用来核对形式化题面、提出辅助引理、指导多智能体探索证明，并用 Lean 4 检查最终证明。系统负责繁琐的形式化推进、分支试错与内核检查，研究者专注于核心构造、引理拆解与研究计划。

下表列出了当前网页研究内测版可直接使用的功能、需要通过 CLI 研究合作开展的能力，以及仍在规划中的模块。

## 浏览器工作台能力（研究内测）

网页工作台（`https://app.theoremos.top`）适合条件明确、结论清楚的数学命题，以及在平台固定标准库或 Mathlib 环境下可表达的单文件 Lean 任务。

| 功能模块 | 可用入口 | 说明与使用边界 |
| :--- | :--- | :--- |
| 访问与计费 | 网页工作台全局<br>[申请入口](./ACCESS.md) | 邮箱白名单研究内测，平台本身免费。用户自备支持 Responses API 的 Key，模型费用直接支付给对应服务商。可通过 [GitHub Issue](https://github.com/LikC1606/TheoremOS/issues/new?template=early-access.yml) 或发信至 `liuzhenhao@westlake.edu.cn` 申请（请勿在公开 Issue 中填写 API Key）。 |
| 自然语言、TeX 与 Lean 输入 | 工作台首页 / 高级 Lean 入口 | 首页接受自然语言或 TeX 数学问题；高级 Lean 入口支持粘贴或导入单个 `.lean` 文件（可含未完成的 `sorry`）。网页端运行在固定版本的 Lean 标准库或 Mathlib 环境中（具体版本与容量限制见界面），不支持上传任意多文件 Lake 工程。 |
| 形式化陈述生成与人工确认 | 工作台首页 / [独立形式化页](https://app.theoremos.top/formalize.html) | 生成的 Lean 陈述会经过编译检查与独立回译对照，帮助发现遗漏假设或量词偏差，但仍需研究者判断其与非形式化原题是否等价。首页审核通过后会自动开始证明；若需人工先把关，可在 `formalize.html` 确认陈述并带入研究草稿后再启动证明。`formalize.html` 使用其默认模型与预算，不继承首页设置或一次性 Key。 |
| 模型服务商配置 | 工作台模型设置区 | 从平台已部署的服务商列表中选择，填入模型名称与 API Key。网页端不支持自定义 Base URL；“检查 Key 与模型”仅测试模型列表连通性，不测试证明能力。 |
| 预算与停止条件 | 首页设置 / 高级 Lean 设置 | 首页可分别设置形式化与证明阶段的时间和 Token 上限；高级 Lean 还可设置研究轮次与 Agent 数量。系统按服务商已报告用量触发停止；因执行中的请求在完成后才计入，该上限不是严格的账单封顶。 |
| 多智能体协同与研究指导 | 高级 Lean 入口 | 可配置 1–4 个 Agent，支持“任务协作”或“独立并行”模式。角色可按需涵盖 Lead、Researcher、Engineer、Reviewer，并非固定四人团队或固定五阶段流水线。研究者可输入指导意见或直接修改研究计划。启用“先审计划再开始”需选择任务协作并配置至少 2 个 Agent；首页自动证明默认使用 1 个 Agent。 |
| 策略预设与调度引导 | 高级 Lean 策略面板 | 提供按计划推进、优先关键路径、延续证明前沿等预设，支持切换完整/精简上下文、保存配置方案，并对 M1/M3/M4/M5 决策点提供文字建议。这些设置属于提示与调度引导，不支持上传可执行插件，也不会改变最终的 Lean 检查标准。 |
| 本账户已验证引理目录 | 高级网页知识目录 / CLI | 高级网页端可搜索本账户已验证引理，查看类型签名、前提、源码与来源，并可在新运行中勾选目录以生成当次运行的固定快照（引理进入新证明环境时仍会重新编译检查）。CLI 端另提供目录构建与批量导入工具。 |
| 过程查看、归档与复核包导出 | 运行详情页 / 档案管理 | 可查看证明源码、验证报告与研究过程，并导出研究档案或候选证明复核包。导入草稿或档案会恢复输入与参数设置，但不会重放或完整恢复历史执行状态（过程记录受容量限制）。部分辅助引理通过编译不代表整题证明完成。 |

## 研究合作与 CLI 能力

当课题超出单文件网页环境，或需要开展底层策略实验时，可通过邮件联系团队（`liuzhenhao@westlake.edu.cn`）讨论研究合作：

| 合作方向 | 适用场景 | 范围与代码边界 |
| :--- | :--- | :--- |
| 策略替换与受控消融 | 算法与形式化研究合作 | 通过 CLI 研究合作接口对 M1–M5 决策策略进行源码级替换、运行受控预算消融实验，或使用批量引理目录构建工具。 |
| 复杂工程与长程课题 | 联合课题攻关 | 若课题涉及自定义包、私有依赖、多文件 Lake 工程或特定 Mathlib/Lean 工具链，请联系团队讨论适配与合作范围。 |
| 仓库与分发边界 | 公开仓库说明 | 本仓库仅包含网站说明、文档、公开证明档案与独立验证材料。TheoremOS 运行时与 CLI 不公开源码或安装器；网页内测资格不包含底层源码授权。 |

## 系统模块现状：已实现与规划中

| 模块 | 当前状态 | 实际作用 |
| :--- | :--- | :--- |
| S1 结构化归档（Archiving） | 已实现 | 保存定理形式化陈述、探索过程、候选证明源码与环境元数据（受存储容量限制），供工作台查看与档案复核。 |
| S3 形式化验证（Verification） | 已实现 | 常规任务通过固定的独立 Lean 4 检查验证最终证明；对于带有原题比较器的基准任务，同时运行固定比较器校验。模型自然语言输出或含 `sorry` 的代码不会算作证明完成。 |
| S2 持续学习（Learning） | 规划中 | 当前的已验证引理检索与历史档案复用属于上下文检索和工程复用，不包含自动参数训练或持续自我学习。 |

## 如何使用

1. **研究单一定理或补全引理**：申请网页内测后，若题目来自自然语言或 TeX，可先在 [独立形式化页](https://app.theoremos.top/formalize.html) 核对生成的 Lean 陈述，确认后带入研究草稿或高级 Lean 入口，按需要选择 Agent 数量与协作模式，并通过研究计划指导证明方向。
2. **本地复核公开证明**：无需注册账号或配置 API Key，直接参考 [独立复核指南](./VERIFY.zh-CN.md) 或下载 [Dimitrov 独立复核包](../proof-kits/dimitrov/README.zh-CN.md) 在本地运行 Lean 内核与比较器检查。
3. **多文件工程或策略实验**：发信至 `liuzhenhao@westlake.edu.cn` 讨论 CLI 研究合作与工程适配。
