# Public materials, reuse, and citation

This repository publishes the TheoremOS website, documentation, proof sources, and research records. The runtime source remains private. The [root notice](../LICENSE) explains the scope of the materials published here.

| Material | Applicable terms and source information |
| --- | --- |
| Project-authored website, documentation, and original branding | Rights are reserved as described in [LICENSE](../LICENSE). For permission to reuse project-owned materials, email [liuzhenhao@westlake.edu.cn](mailto:liuzhenhao@westlake.edu.cn). |
| Archived proof sources and research records | Follow the file's own license, accompanying terms, and original source. This repository does not apply a new blanket license to these records. |
| Lucide and Feather icons | [Lucide/Feather license](../lucide-LICENSE.txt): ISC and, for the listed Feather-derived icons, MIT. |
| Inter font | [Inter license](../assets/fonts/Inter-LICENSE.txt): SIL Open Font License 1.1. |
| GSAP | [GSAP notice and license reference](../assets/licenses/gsap-NOTICE.txt). |

For example, [the fractional expectation threshold proof](../accepted/annals_fractional_expectation_thresholds/Submission.lean) carries David Ledvinka's copyright notice and an [Apache-2.0 license](https://www.apache.org/licenses/LICENSE-2.0) header. That header refers to the original source's license, and those terms continue to apply to the file. Other packages should be checked individually; a source link or public download does not by itself identify a reuse license.

Original source revisions, author/model attribution, and acceptance links are recorded in [accepted.json](../accepted/accepted.json), [submitted.json](../submitted/submitted.json), and the individual [OpenAI Math records](../data/proofs/). Retain the relevant source information when referring to a proof.

Use [CITATION.cff](../CITATION.cff) to cite TheoremOS as a research tool. When discussing a particular theorem or archived proof, also cite its original mathematical and proof sources. Instructions for checking a proof are in [VERIFY.md](VERIFY.md).
